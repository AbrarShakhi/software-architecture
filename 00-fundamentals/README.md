# 00 — Fundamentals

> The bedrock principles every software system should be built on, regardless of language, framework, or scale.

These are not optional guidelines — they are the difference between a codebase that stays maintainable for years and one that collapses under its own weight in months.

## Why Start Here?

Every architecture pattern in later sections is an application of these fundamentals at a larger scale:

- **Microservices** is Separation of Concerns applied to services
- **Clean Architecture** is SOLID applied to entire systems
- **TDD** is a discipline that enforces clean, testable code

Get these right and everything else becomes easier.
